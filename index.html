cobol-bench

AI evaluation · benchmark

Can AI coding assistants really understand legacy COBOL? A small, rigorously validated benchmark: 8 realistic business programs × 4 task types (predict, explain, translate, generate) = 32 scored prompts, running on the free GnuCOBOL compiler.

  • The COBOL programs and independent Python oracles agree on 4,053 inputs, including edge cases and mined adversarial cases.
  • Mutation testing: the test suites catch 355 of 373 planted bugs (95.2%); all 18 survivors were hand-checked as equivalent.
  • Finding: a float-based translation of the loan program is wrong on only 0.1% of random inputs, and the first test suite (0 of 26 tests) missed it. Random tests aren't enough.
  • COBOL
  • GnuCOBOL
  • Python
  • Mutation testing

cobol-forge

Reinforcement-learning environment

An RL environment of procedurally generated COBOL business programs, with ground truth from the real GnuCOBOL compiler and rewards designed to resist reward hacking. It targets what breaks legacy modernization: fixed-point storage, ROUNDED vs truncation, silent overflow, sign loss and exact report formatting.

  • Each program is rendered twice by independent code paths, COBOL and an exact-rational Python reference, with 0 disagreements on about 4,000 random programs.
  • Four program families (calculations, tables, control breaks, string handling), each with five difficulty levels.
  • A frozen dataset of 2,000 train / 500 test tasks, or unlimited procedural generation.
  • Python
  • COBOL
  • RL environments
  • verifiers

Verified Practice (stem-packs)

Generator · practice packs

Generates print-ready practice packs (worksheets plus full worked solutions) where every answer is machine-checked before it's typeset, in three parallel versions with the same skills and different numbers.

  • Each problem type has its own verifier: high-precision numerical differentiation for calculus, ODE simulation for physics, and exact enumeration plus Monte Carlo for probability.
  • A self-test plants wrong answers (sign flips, dropped terms, off-by-one counts, wrong units) and requires the verifier to reject every one.
  • Four packs so far: Calculus I derivatives, Calculus II integration, Physics I kinematics, and discrete probability.
  • Python
  • SymPy
  • SciPy
  • NumPy

Pairs-trading system

Quant · automation

A statistical-arbitrage pairs-trading system: backtests, a scanner that checks candidate pairs out of sample, and a bot that paper-trades the selected basket through the Alpaca API.

  • One config file is the single source of truth for both the backtest and the live bot, after the two had drifted apart.
  • GitHub Actions runs the bot on trading days and opens a monthly pull request proposing basket updates for review.
  • Rolling hedge ratios, a regime filter, and unit-tested position sizing.

Neon Dash

Mobile game · PWA

A neon endless lane-dodger for phones. Swipe between lanes, dodge the blocks, and grab orbs to build a combo multiplier while the speed ramps up. It installs to the home screen and runs fullscreen and offline.

  • No dependencies and no build step: about 580 lines of vanilla JavaScript drawing to a single canvas.
  • Fair spawning: the safe lane moves at most one lane per row, so every pattern can be dodged.
  • Sound is synthesized with WebAudio (no audio files), and a service worker caches everything for offline play.

Irrigation (working title)

Puzzle game · in progress

A pipe-rotation puzzle with a farm meta layer: tap tiles to turn them until every plant has water, then spend coins upgrading the farm.

  • Levels are generated backwards from a solved spanning tree, so every level is solvable by construction.
  • A deduction-plus-search solver checks each level for uniqueness and par, and scores its difficulty to fit the curve.
  • 100 generated levels; the test suite checks every one is well-formed, solvable, and has a correct par.
